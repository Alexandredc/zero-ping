Silence GitHub. Keep what needs you.

Zéro Ping turns GitHub notifications into one sorted list of what waits on you: reviews, replies, your pull requests and your team’s, each with its Slack threads and an AI summary. It runs on your machine, with your own tokens.

    Traités
    1. 1

      Everything arrives

      The server polls GitHub at the pace GitHub asks for, with If-Modified-Since: unchanged checks cost no quota. A review-requested search runs every five minutes on top.

    2. 2

      The noise is filed

      Merged or closed PRs, bots, CI activity, releases and the authors you choose go to Traités. The rules never touch what waits on you.

    3. 3

      What’s left is scored

      Review asked of you, last missing reviewer, waiting time, size, CI, urgent labels, and the urgency Jev estimates. Every point is explained.

    4. 4

      Context is attached

      An agent finds the Slack threads that cite each PR, and an AI summary tells you where things stand and what is expected from you.

    Local and private

    Nothing to host. Nothing to sign up for.

    Zéro Ping is a Node server on your laptop with an embedded database. It only talks to services you already use, with your own credentials.

    GitHub API

    With gh auth token. Polls with If-Modified-Since, so a 304 costs no quota.

    Jev (optional)

    With your TypeSafe key, only when an item’s content changes. Without it, deterministic rules.

    Quick start

    Running in four commands.

    • Node.js 22.12+ and pnpm
    • GitHub CLI signed in with gh auth login, or a GITHUB_TOKEN
    • For AI and Slack: Claude Code with the Slack connector, or Codex with a Slack MCP server
    • Optional: a TypeSafe API key for Jev scoring
    • Optional: macOS, for the Dock app with a ping badge
